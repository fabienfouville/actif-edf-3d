Parc Électrique 3D

Une carte 3D du parc de production français où chaque centrale se clique. La fiche montre quand l'actif est appelé dans le merit order du spot, comment il est couvert et ce qu'il vaut, avec le JSON derrière chaque chiffre. Voici quatre directions visuelles, la fiche commune, les sources de données publiques et la façon de tout automatiser gratuitement.

Commun à toutes les directions

La fiche actif, au clic

Le clic ouvre un panneau latéral sur ordinateur et une feuille qui monte du bas sur téléphone. Quatre onglets : Merit, Couverture, Valo, JSON. La liste des tranches du site est dans la fiche, et chaque onglet a un lien vers le fichier JSON qui l'alimente.

Quand l'actif est appelé : une carte heure × semaine de la marge spot − coût marginal. On voit l'arrêt pour rechargement et les heures solaires où le prix tombe sous le coût.

Couverture : part vendue à terme par année, curseur de scénario spot, revenu décomposé (terme, spot, reversement VNU, coûts).

Le JSON brut de l'actif, copiable, avec ses sources. Dessous, les tranches du site et leur état.

Sans serveur

Automatisation

Des GitHub Actions planifiées récupèrent les données, calculent les indicateurs et écrivent des fichiers JSON statiques. Le site lit ces fichiers. Il n'y a ni serveur ni base de données à payer.

1 · collecteGitHub Actions

Cron horaire et quotidien. Scripts Python qui appellent RTE, ENTSO-E et éCO2mix avec les clés stockées en secrets.

2 · calculbuild.py

Coûts marginaux, rang dans le merit order, heures appelées, prix capté, couverture, DCF.

3 · stockageJSON versionnés

Historique compact dans une branche data dédiée, pour ne pas alourdir le code.

4 · diffusionGitHub Pages

Site statique et JSON servis en HTTPS. Le bandeau live peut aussi lire éCO2mix en direct.

Deux points à surveiller : les tâches planifiées de GitHub peuvent partir avec quelques minutes de retard, et GitHub les met en pause après 60 jours sans activité sur un dépôt public. Les commits quotidiens de données suffisent normalement à les garder actives.

Ce que la fiche calcule

Merit order, couverture, valorisation

Quand l'actif est appelé

CMg = combustible / rendement + facteur CO2 × prix EUA + O&M variable
  • Constaté : heures où la tranche produit, d'après la production par groupe.
  • Expliqué : chaque heure, on empile les capacités disponibles par CMg croissant. On obtient le rang de l'actif, la filière marginale et l'écart entre le prix modélisé et le prix réel.
  • Indicateurs : facteur de charge, heures en marge, prix capté, heures où la filière fixe le prix.

Couverture financière

  • Nucléaire EDF : part vendue à terme par année de livraison (publiée par EDF), reste exposé au spot, reversement VNU au-delà des seuils.
  • Gaz et charbon : spark spread et dark spread verrouillés en achetant gaz et CO2 à terme.
  • Éolien et solaire : complément de rémunération ou PPA à prix fixe, taux de capture.
  • Curseur de scénario spot, revenu décomposé en cascade.

Valorisation

VAN = Σ (marge − fixes − capex) / (1 + WACC)^t
  • Sur la durée de vie restante (ex. 60 ans pour le nucléaire).
  • Curseurs : WACC, prix long terme, disponibilité, CO2.
  • Graphique de sensibilité (tornado) sur ces quatre paramètres.
  • Hydraulique : valeur de l'eau ; STEP : écart pointe / creux × rendement.

EDF ne publie sa couverture qu'en agrégé. La couverture par tranche est donc une répartition au prorata, et la fiche le dira. Tous les paramètres (rendements, seuils VNU, coûts) vivent dans data/params.json avec leur source.

Simple et léger

Structure du code

Pas d'étape de build : du HTML et des modules JavaScript natifs, deux librairies chargées depuis un CDN (MapLibre GL pour la carte, uPlot pour les graphiques, qui pèse environ 50 ko). Les calculs financiers sont des fonctions pures, faciles à tester.

Gratuit

Hébergement

GitHub Pages recommandé

  • Gratuit, HTTPS, dans le même dépôt que le code et les Actions.
  • Adresse du type fabienfouville.github.io/actif-edf-3d.
  • Condition : dépôt public sur le plan gratuit.

Cloudflare Pages

  • Gratuit, fonctionne avec un dépôt privé.
  • Un Worker peut servir de relais pour du live plus fréquent.

Téléphone et ordinateur

  • Mise en page adaptative : panneau latéral sur grand écran, feuille glissante sur mobile.
  • Installable comme une app (PWA) depuis le navigateur.
  • Moins de colonnes 3D affichées et ombres coupées sur petits appareils.

Ton tour

À décider avant de coder

  1. Direction visuelle : A, B, C, D, ou le mélange A + C + jeu de B que je recommande ?
  2. Dépôt public ou privé ? Public permet GitHub Pages gratuit. Privé, je passe sur Cloudflare Pages.
  3. Périmètre de la V1 : nucléaire EDF et grandes centrales ≥ 100 MW une par une, éolien et solaire agrégés par région ?
  4. Comptes : peux-tu créer un compte RTE Data et demander un jeton ENTSO-E (gratuits, je te guide) ? Sans eux, je démarre avec éCO2mix seul.
